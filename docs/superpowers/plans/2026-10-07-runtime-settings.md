# Runtime 与服务配置实施计划

目标：落实用户已确认的 Codex CLI / WorkBuddy / LLM API 切换与页面配置，默认 Codex；发布审核链不变。

架构：独立本机配置文件保存密钥，普通 API 只返回设置状态；独立进程适配器返回结构化内容。配置保存影响后续调用，不回退至其他服务。

- [x] 配置模块：原子保存、0600 权限、密钥不回显、URL 和参数校验，测试覆盖持久化和错误输入。
- [x] Runtime 模块：非交互 CLI、独立目录、进程超时、输出限制、JSON 解析、禁用可用的工具能力；版本检查不调用模型。
- [x] 服务集成：统一文案入口，GRSai 配置即时生效，不改变审核与发布 API。
- [x] 页面：执行器切换、路径/模型/超时、服务地址/密钥、保存及可用性检查。
- [x] 验收：54 项测试、语法检查、浏览器设置页保存与执行器检查通过。Codex 0.156.1 / WorkBuddy CLI 2.115.0 版本检查成功，尚未验证真实模型生成。审查发现的未收尾图像任务换服务问题已修复并加入回归测试。
