# 导入真实研究数据

使用 `examples/research-template.csv` 的表头填写数据，也可导入对应 JSON 对象数组。模板不含虚构样本。

| 字段 | 含义 |
| --- | --- |
| category | 明确的商品品类，例如水杯 |
| candidate | 你已核对的候选商品名称，不要直接填笔记标题 |
| url | 该条数据的来源链接 |
| sampledAt | 数据采样时间，建议带时区，例如 ISO 8601 格式 |
| likes / comments / collects | 来源中实际可见的点赞、评论、收藏数 |
| sales | 来源实际提供的销量数值；缺失时留空 |

没有数据请留空，不要用零代替未知。零表示来源明确显示为零。

不同商品即使名称相似也应分开记录；同一商品不同规格或不同统计口径应在名称或附加说明中区分。只在时间范围和指标口径可比时比较。一次销量快照不能证明增长，点赞总量也不能换算成交量。

研究报告只覆盖导入和采集的样本。用户导入的销量属于来源声明，需要自己核对其可靠性；本工具不将其包装为平台官方全量排名。
